# Spanish 1000 — ملاحظات الإصدار (versionCode 7 · versionName 6.0)

## ما الجديد في هذا الإصدار
- نظام تصميم موحد (ألوان فاتحة وداكنة، أزرار، بطاقات، شارات، حالات فارغة/تحميل/خطأ).
- 5 شخصيات كرتونية أصلية بتعبيرات متعددة، و16 ملصقًا قابلًا للجمع.
- أيقونة تطبيق Adaptive Icon وشاشة Splash متناسقة مع الهوية.
- الشاشة الرئيسية: حلقة تقدم للهدف اليومي مرتبطة ببيانات التقدم الفعلية.
- أداتا فحص جديدتان: سلامة المحتوى وسلامة الموارد والـ Manifest.

## ما لم يتغير
- مفاتيح التخزين المحفوظة (`habla_progress`) كما هي؛ لا توجد Migration مدمرة.
- المسارات والدروس والمراجعة المتباعدة والقاموس والمحادثات والاستيراد/التصدير تعمل بالمنطق الحالي.

## الميزات التي تعمل دون إنترنت
فتح التطبيق، الدروس، المحتوى المحلي، القاموس، التقدم، المفضلة، المراجعة، الإحصاءات، المكافآت، الإعدادات، الاستيراد والتصدير، والشخصيات والملصقات (أصول محلية).

## الميزات التي تحتاج إنترنتًا أو خدمات الجهاز
- **الصوت الإسباني (TTS):** يعمل بمحرك النطق في الجهاز. إن لم تكن حزمة الإسبانية مثبتة يظهر تنبيه بدل الصوت.
- **التعرف على النطق:** يعتمد على خدمة التعرف على الكلام في الجهاز، وقد يحتاج اتصالًا حسب الجهاز.
- **المحادثات الذكية عبر خدمة خارجية:** غير مفعّلة في هذا الإصدار، ولا تحتوي الحزمة أي مفتاح API.

## التحقق قبل الإصدار
- `tools/check_learning_logic.py` — ناجح.
- `tools/validate_content.py` — 0 أخطاء، 24 تحذيرًا معروفة (مراجعة لغوية مطلوبة).
- `tools/validate_resources.py` — 0 أخطاء.
- بناء Debug وRelease (R8) ناجح؛ `aapt dump badging` يؤكد minSdk 23 وtargetSdk 36.
- **لم يُشغَّل التطبيق على جهاز أو محاكي**، ولم تُختبر الواجهات بصريًا.

## قيود معروفة
- Release APK **غير موقّع**. التوقيع يتم بمفتاح نشر خارج المستودع.
- المحتوى الحالي: 1000 عنصر لكل مسار، وليس الأهداف المطلوبة كاملة (500 جملة، 200 سؤال، 100 تعبير).
- الترجمة المصرية والفصحى موجودتان لكل عنصر في المسار الثاني فقط بصيغة مختلطة؛ الفصل المنهجي لم يُنفذ بعد.

## توقيع الإصدار (خارج المستودع)
```sh
apksigner sign --ks <release.jks> --out Spanish1000-release.apk releases/app-release-unsigned.apk
```
المفتاح وكلمة المرور لا يُحفظان في المستودع ولا داخل APK.
